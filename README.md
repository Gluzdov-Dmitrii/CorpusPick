# CorpusPick

Локальный помощник для подготовки каталога документов рядом с Windows Explorer. Просмотр остаётся в Explorer; CorpusPick сохраняет происхождение файлов, убирает вложенность, находит точные дубли и показывает статистику.

## Запуск

Windows, Python 3.10+ с Tcl/Tk. Установите зависимости: `python -m pip install -r requirements.txt`. Затем откройте `Start-CorpusPick.cmd` или выполните `python -m corpuspick`.

## Восстановить структуру из бэкапа для уже плоского каталога

1. **До открытия бэкапа** включите галочку **«Бэкап: открыть без изменений»**. Нажмите **«Открыть каталог»** и выберите бэкап с исходными подпапками.
2. Нажмите **«Сохранить CSV»**, выберите файл **вне каталога документов**. Программа читает файлы для SHA-256 и сохраняет структуру, включая пустые папки. В режиме бэкапа Unlock, перенос, удаление и запуск Word запрещены; ни содержимое файлов, ни Zone.Identifier, ни структура каталогов программой не меняются. Состояние анализа записывается только во внешний пользовательский каталог.
3. Снимите галочку бэкапа и откройте рабочий плоский каталог. В обычном режиме Unlock автоматически снимает отметку «скачано из интернета» со вложенных файлов. Не включайте обычный режим для бэкапа, который должен оставаться нетронутым.
4. Нажмите **«Загрузить CSV»**. Файлы сопоставляются по SHA-256 и размеру, поэтому их текущие имена и вложенность могут отличаться.
5. Колонка **«Исходный путь / варианты»** покажет прежние папки. Ищите по их названию, выделяйте строки и считайте статистику или удаляйте выделенные файлы. Действия используют текущие пути файлов, а пути из CSV служат только данными о происхождении.

Если один SHA-256 встречается в нескольких исходных папках, однозначно восстановить происхождение конкретной побайтовой копии невозможно. Для неё показываются **все возможные исходные пути**. Программа не назначает папку случайным образом. Если SHA получить не удалось или содержимое изменилось относительно бэкапа, совпадение не заявляется.

CSV имеет заголовок, разделитель `;` и кодировку UTF-8 BOM. Поля: версия схемы, вид строки (файл/каталог), текущий относительный путь, исходный относительный путь, размер, SHA-256 и список возможных исходных путей. Это не произвольный CSV из стороннего инструмента. Метки формул экранируются при сохранении и восстанавливаются при загрузке. CSV содержит чувствительные имена/пути: не публикуйте его в Git.

## Перенос, остановка и сохранение

**«Перенести в корень»** работает со всем каталогом независимо от выделения и фильтра. Совпадающие имена получают суффиксы без перезаписи. Пустые папки можно удалить отдельно.

CSV структуры автоматически сохраняется **до первого перемещения** и обновляется после завершения/остановки: `%LOCALAPPDATA%\CorpusPick\<идентификатор>.structure.csv`. Точный путь выводится по завершении операции. Если запись CSV не удалась, перемещение не начинается. Для собственного расположения и переносимой копии используйте **«Сохранить CSV»**. Исходные папки остаются в CSV и сессии после физического выравнивания.

**«Стоп» / Esc** приостанавливает работу и сохраняет прогресс. Для продолжения переноса нажмите ту же кнопку **«Перенести в корень»**; для подсчёта — **«Статистика»**. Это поддерживается и после перезапуска. **«Сбросить план»** отменяет только оставшиеся шаги, завершённые переносы не откатывает.

Хеширование прерывается между блоками чтения; перенос — между файлами. Обычная статистика прерывает текущий обработчик; уточнение через Word может ждать текущий документ до 120 секунд. Медленный системный вызов диска/облачного провайдера не прерывается принудительно. Закрытие занятого окна сначала запрашивает остановку.

## Интерфейс и выбор

- Слева от имени — номер файла. **Ctrl/Shift** выделяют несколько строк, **Ctrl+A** — все видимые, **Esc** снимает выделение, когда операция не выполняется.
- Колонки **Стр. / Рис. / Табл.** всегда видны. Приложения больше не считаются.
- Сортировка работает по каждому заголовку, повторное нажатие меняет направление; числа сортируются как числа.
- Без выделения итог внизу относится ко всему каталогу. При выделении — только к выбранным файлам. Для возврата к общему итогу снимите выделение. Фильтр сам по себе не меняет общий итог.
- **Enter / двойной щелчок / ПКМ → «Показать в Проводнике»** передаёт все выделенные файлы в Explorer. Для каждой текущей папки открывается окно с её частью выделения. В Проводнике можно вырезать всю выделенную группу и вставить в нужный каталог; затем F5 обновляет CorpusPick. Контекстное меню также копирует названия и пути. Метки и клавиша 2 удалены.
- **Delete** отправляет выделенные файлы в системную корзину после подтверждения. **«Удалить дубликаты»** сохраняет один экземпляр группы: ближе к корню, затем по имени. При наличии выделения удаляются только выделенные лишние копии; сохраняемый экземпляр может находиться вне выбора. Содержимое обеих копий проверяется перед удалением.
- Меню «Инструменты» и отдельной кнопки Unlock нет. Unlock снимает только Zone.Identifier; права доступа, пароли и блокировку открытым редактором не снимает.

## Быстрая статистика без Word

При открытии и обновлении читается только список файлов и сохранённые результаты. Подсчёт страниц, рисунков и таблиц запускается кнопкой **«Статистика»**: по выбранным документам или всему каталогу, если ничего не выделено. Неизвестные значения обозначены `—`, а не нулём. Результаты появляются после завершения или остановки; во время работы показан счётчик обработанных файлов.

| Формат | Страницы | Рисунки / таблицы |
| --- | --- | --- |
| PDF | Число страниц PDF, без запуска Word | Не считаются |
| DOCX | Сохранённое число страниц из свойств, знак `≈`; может отсутствовать или устареть | Графические объекты и таблицы основного текста из XML |
| DOC | Сохранённое число страниц из OLE-свойств, знак `≈`; может отсутствовать или устареть | В быстром режиме неизвестны |

**«Статистика»** продолжает быстрый подсчёт для выбранных документов или всего каталога, если ничего не выделено. **«Уточнить Word»** отдельно запускает установленный Word для точных страниц после перевёрстки и счёта Shapes/InlineShapes/Tables у DOC/DOCX. Файлы не сохраняются; макросы и обновление ссылок отключаются. Подключённые службы Office зависят от локальных настроек. В режиме бэкапа этот режим запрещён из-за возможных временных файлов Office.

В итогах знак **`>`** используется по запросу пользователя как индикатор **неполного подсчёта**, а не строгое математическое неравенство: например, рисунки/таблицы посчитаны по Word, а в выборе есть PDF. Когда выбраны только Word и все значения известны, `>` не ставится. Для неполных данных DOC он остаётся и в выборке Word. `≈` для сохранённых страниц не снимается из-за выбора только Word. Рядом указано покрытие `известно/всего`.

## Производительность

Неизменившиеся файлы не хешируются повторно: кэш проверяется по идентификатору файла, размеру и времени изменения. При открытии SHA не вычисляется: он рассчитывается кнопкой «Найти дубли», при работе с CSV, удалении дублей и переносе. Первое вычисление SHA-256 всё равно требует прочитать все байты — для большого архива это может быть долго. Оно необходимо для сопоставления разных каталогов и точных дублей.

Обычная статистика считается в отдельном процессе: медленный разбор PDF/DOCX не занимает процесс окна. Лимит — 30 секунд на документ, затем файл пропускается с ошибкой; кнопка «Статистика» повторяет неудавшиеся попытки. «Стоп» завершает текущий обработчик и сохраняет готовые результаты. Список больше не перестраивается каждую секунду. Отдельный режим «Уточнить Word» по-прежнему ожидает завершения текущего документа или таймаута Office.

При переносе больше нет полного хеширования до и после каждого прохода, полного переписывания состояния для каждого файла и линейного поиска файла в списке. Короткий журнал завершённых перемещений синхронизируется на диск после каждого шага; полная сессия сохраняется в начале/конце. Нумерация коллизий также не перебирает заново все прошлые суффиксы.

На искусственном наборе из 500 маленьких файлов с одинаковыми именами в разных папках: первичный обход/хеширование 3,61 с, перенос с кэшем и CSV 2,70 с в среде разработки. Это не оценка скорости реального архива или сетевого диска. Оставьте документы закрытыми во время переноса, работайте с копией архива.

## Состояние и проверки

Состояние, короткий журнал и автоматический CSV находятся в `%LOCALAPPDATA%\CorpusPick`, вне исходного каталога и Git. Исходные документы/кэши пользователя агентом не читаются. Python-часть не отправляет сетевых запросов и не логирует извлечённый текст. Уже завершённые переносы автоматически не отменяются.

`python -m unittest discover -s tests -v`

Опционально `CORPUSPICK_TEST_WORD=1` включает проверку Word на искусственном DOCX; `CORPUSPICK_TEST_RECYCLE=1` — проверку корзины на искусственном файле с восстановлением. Все тесты используют только синтетические документы.

Правой кнопкой по строке → **«Показать в Проводнике»** открывает текущие папки и выделяет все выбранные файлы, в том числе после загрузки CSV исходной структуры. **«Скопировать название»** копирует имя с расширением; для нескольких выделенных файлов — по одному на строку.

## Выбор, очистка префиксов и похожие названия

Ctrl+A выделяет все видимые строки и работает в русской/английской раскладке, в том числе после нажатия кнопки. В поле поиска сочетание выделяет текст. Ctrl/Shift позволяют выбрать несколько файлов.

**«Убрать префикс»** открывает поле «Сколько символов убрать?». Введите положительное целое число и нажмите ОК: у выбранных файлов удалится указанное количество символов слева. Отмена закрывает окно без изменений. Расширение сохраняется; пустые/недопустимые имена и конфликты пропускаются без перезаписи. Исходные пути и статистика сохраняются. Операция использует журнал переноса и автоматический CSV; после Stop оставшиеся шаги можно выполнить кнопкой «Перенести в корень» или отменить через «Сбросить план». В режиме бэкапа переименование запрещено.

**«По похожести»** обрабатывает весь выбранный каталог каскадом. Строгие отпечатки ищут точные/близкие версии, а локальный ML группирует извлечённый текст по теме. Тематический конвейер: hashed TF-IDF слов и пар слов → LSA (TruncatedSVD, 64 измерения) → HDBSCAN. Число тем заранее не задаётся; HDBSCAN оставляет неуверенные документы выбросами. Текст названия и путь не подаются модели. Для PDF без текстового слоя дополнительно сравниваются визуальные отпечатки крупнейшего встроенного изображения на первой, средней и последней страницах. OCR для этого не нужен.

Для тематических признаков берутся первые 3000 извлечённых слов PDF/DOCX/TXT/MD/CSV/TSV. В кэш записывается сжатый вектор из 8192 числовых ячеек, без слов и исходного текста. При обновлении старого кэша байтовые отпечатки не пересчитываются: добавляется только этот ограниченный текстовый проход. Ошибки не повторяются при каждом нажатии; для явного повтора используйте сброс кэша. Запуск идёт в отдельном процессе, **Стоп** прерывает текущий файл. При изменении состава/идентификаторов файлов отображаемая группировка сбрасывается.

Сначала показываются группы, подтверждённые содержимым; более многочисленные группы идут раньше. Затем только среди оставшихся файлов ищутся похожие названия при одинаковом формате и разнице размера не более чем вдвое. Этот резервный этап не может разбить или перемешать группы, уже найденные по содержимому. Остаток помещается в конец по формату и размеру: одинаковое расширение без учёта регистра, отношение минимального размера к максимальному в одном блоке не менее 95%, внутри — возрастание размера. Проверка относительно самого маленького файла исключает цепочки с постепенно растущим разбросом. Основание выбранной строки явно отличает содержательную, резервную и чисто размерную группу.

**Файлы больше 128 МиБ** (134 217 728 байт), включая ZIP и расчётные файлы, не читаются для похожести и сразу попадают в такие блоки по формату и размеру. Порог действует для всех форматов, включая большие PDF/DOCX; старые отпечатки больших файлов сохраняются, но в этой группировке не используются. ZIP не распаковывается даже ниже порога, сравниваются байты контейнера. «Найти дубли», удаление точных дублей и CSV с SHA работают отдельно и могут читать большие файлы полностью.

**Сброс кэша:** ПКМ по кнопке «По похожести» / «Снять группировку» → «Сбросить кэш похожести». После подтверждения удаляются только отпечатки похожести текущего каталога; исходные пути, журнал переносов, CSV, SHA точных дублей и статистика остаются. Затем можно повторить сравнение. Состояние хранится в `%LOCALAPPDATA%\CorpusPick`; не удаляйте всю папку ради пересчёта похожести — там также сохранена исходная структура. Сброс разрешён и в режиме бэкапа, поскольку записывает только внешнее состояние программы.

- **Байты любого формата:** SHA-256 для точных копий и отпечатки фрагментов для близких. Для крупных файлов используются границы, зависящие от содержимого (Gear rolling hash, блоки 512–8192 байт), для файлов до 32 КиБ дополнительно перекрывающиеся 16-байтные фрагменты. Вставка или замена байта меняет часть отпечатков, а не всё сравнение.
- **DOCX:** извлекается текст абзацев, включая таблицы, колонтитулы, сноски. ZIP-сжатие и служебные метаданные не определяют текстовое сходство. Изображения и вёрстка текстовым сравнением не проверяются. Большая/повреждённая XML-часть может не пройти ограничение парсера.
- **PDF:** извлекается доступный текст всех страниц. Если текста почти нет, pypdf декодирует крупнейшее встроенное изображение на первой, средней и последней страницах, а CorpusPick сохраняет 512-битный перцептивный отпечаток яркости и контуров. Он позволяет сопоставить одинаковые или визуально близкие сканы после иного JPEG-сжатия. Он не понимает смысл двух разных изображений одной темы; для этого понадобился бы OCR. При шифровании или ошибке декодирования остаётся байтовый сигнал и резерв по названию/типу/размеру.
- **TXT/MD/CSV/TSV:** Unicode (включая UTF-16 BOM), при необходимости CP1251. Текст превращается в перекрывающиеся последовательности пяти слов; цифры сохраняются.
- **DOC и другие форматы:** только байтовое сходство; семантического извлечения старого Word нет.

В кэше — SHA и до 256 минимальных 64-битных хешей фрагментов (bottom-k/KMV), тематический хеш-вектор, количества и статусы. Исходный извлечённый текст не записывается в кэш, логи или IPC. Строгое сходство оценивается по общим отпечаткам: порог 85% для байтов, 82% для текста, отношение длин не менее 80%; текстовый сигнал требует хотя бы 10 слов. Это оценка общих фрагментов, не доля идентичных байтов и не вероятность дубликата. Короткие/однообразные файлы, сильное пересохранение сканов и иной порядок содержимого могут дать пропуски. SVM и трансформеры не используются; тематический слой — неконтролируемая кластеризация HDBSCAN над LSA-векторами.

Текст названия и путь полностью исключены из основного сравнения и тематического ML. Для версий используется complete-link: сначала объединяются самые близкие по содержимому файлы, затем группы, у которых совместимы все пары участников. После этого связи близких версий объединяются с тематическими группами HDBSCAN. Имена проверяются исчерпывающе только в оставшихся блоках одного формата и близкого размера. Ограничение индексных списков в 256 кандидатов снято; на больших наборах близких версий число сравнений и потребление памяти могут расти квадратично.

Без успешного содержательного сигнала файл может войти только в явно помеченную резервную группу по названию/формату/размеру либо в завершающий размерный блок. Под выбранным файлом показано основание: точные байты, близкий текст, визуально близкие страницы PDF, близкие байты, резервное название либо только формат/размер. Ошибки чтения/извлечения доступны в фильтре «Есть ошибки». Новый алгоритм дополняет существующий кэш тематическими и визуальными отпечатками без повторного полного чтения байтов.

**Похожие файлы автоматически не удаляются.** «Удалить дубликаты» по-прежнему работает только с точным SHA-256 и повторной проверкой перед корзиной. Отбор похожих версий — вручную через выделение и Проводник.

После **«По похожести»** пункты сортировки в меню заголовка ▾ сортируют внутри каждой группы, сохраняя порядок групп. В меню можно выбрать направление сортировки. **«Снять группировку»** возвращает обычный список и сортировку по всему каталогу. При открытии другого каталога группировка сбрасывается.

После группировки текст каждой строки окрашен цветом её группы. Цвет сохраняется при дополнительной сортировке колонок внутри групп; одинаковый цвет означает один блок текущего результата. Отдельной карты нет. Для точного основания выделите строку: под таблицей будет указано сравнение содержимого, ML, резервное название или только формат/размер.

## Фильтры колонок

Нажмите заголовок **«Файл ▾» → «Фильтр…»**. Введите слова, например `насос испытания`: по умолчанию должны встретиться все части слов, в любом порядке. Галочка **«Слова целиком»** позволяет отличить `акт` от `контракт`. Есть режим любого слова и поле исключений. Фильтр названия проверяет только имя файла, а не исходную папку из CSV. Общая строка поиска продолжает искать и по путям.

Такое же меню есть у каждой колонки: для типа/папок — текстовый фильтр, для байт/страниц/рисунков/таблиц — включительные границы «От» и «До». Неизвестные значения не проходят числовой фильтр. Фильтры колонок соединяются условием И, сочетаются с группировкой и сортировкой. Активный фильтр отмечен **●▾**. **Ctrl+A** выделяет все видимые результаты; их можно передать Проводнику. Пустые поля снимают фильтр колонки; в меню есть снятие одного или всех фильтров. Новый каталог сбрасывает фильтры колонок.

**«Найти дубли»** отдельно проверяет SHA-256 всех файлов выбранного каталога, включая подпапки, без удаления и подсчёта страниц. В колонке «Дубль»: **«Не проверен»** — SHA ещё не вычислен (раньше показывался `?`); **#номер** — группа точных копий; **—** — среди проверенных файлов совпадений нет. Пока проверка неполная, отсутствие группы не доказывает уникальность во всём каталоге. После остановки повторная кнопка продолжает проверку, используя кэш. При первом запуске читаются все байты файлов, поэтому большой архив требует времени.

Оптимизация байтового анализа: rolling hash вычисляется только там, где возможна граница блока, без добавления каждого байта в Python-буфер. Отпечатки совместимы с прежним кэшем. На искусственном файле 16 МиБ расчёт байтовых отпечатков ускорился с 15,09 до 5,25 с (примерно 2,9 раза); это не оценка времени извлечения PDF/Word-текста или всего реального архива. Для применения обновления к текущей обработке нажмите «Стоп», дождитесь сохранения, перезапустите приложение и снова запустите «По похожести».
