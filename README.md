# CorpusPick

Простой локальный помощник для работы рядом с Windows Explorer и его Preview. Просматривайте и сортируйте подходящие документы в Explorer; CorpusPick приводит в порядок вложенные папки и показывает состав документов.

## Запуск

Windows, Python 3.10+ с Tcl/Tk. Двойной щелчок по `Start-CorpusPick.cmd` или `python -m corpuspick` из каталога проекта.

Папки, Unlock и статистика DOCX работают без сторонних пакетов. Для числа страниц PDF: `python -m pip install -r requirements.txt`. Для полного пересчёта DOC/DOCX нужен установленный Microsoft Word.

## Интерфейс

Три основные кнопки:

- **Открыть каталог** — рекурсивный список всех файлов.
- **Перенести в корень** — перенести файлы всех подпапок без перезаписи совпадающих имён; имена получают суффикс. Действие относится ко всему каталогу независимо от фильтра.
- **Удалить пустые папки** — удалить только пустые подпапки. Непустые папки и ссылки остаются.

Список растягивается вместе с окном, ширина колонок меняется перетаскиванием. Есть поиск по пути, фильтры и сортировка по заголовку (повторное нажатие меняет направление). Видны тип, размер в байтах и группы точных дублей SHA-256. Знак `?` в дублях означает, что хеш получить не удалось.

**F5** обновляет список после сортировки в Explorer. **Enter / двойной щелчок** показывает выбранный файл в Проводнике. Правой кнопкой можно скопировать полный путь. Исходный путь до переноса виден внизу.

Предпросмотра, экспорта CSV, оценок 0/1/2, типов «отчёт/письмо» и статуса проверки больше нет. Осталась одна необязательная метка **«Скорее да»**: клавиша **2** или контекстное меню ставит/снимает её, не перемещая файл. Старые оценки 2 отображаются этой меткой при совпадении содержимого.

## Инструменты

**Unlock — разблокировать все вложенные файлы** снимает поток `Zone.Identifier` рекурсивно, как [Unblock-File](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/unblock-file). Это отметка скачивания из интернета. Пароли, права доступа и занятость файла другой программой не снимаются. Содержимое и прочие потоки сохраняются. Применяйте к файлам, которым доверяете. После команды выводятся количества разблокированных файлов и ошибок.

**Подсчитать состав DOCX / страницы PDF** добавляет колонки статистики:

| Показатель | DOCX без Word | PDF |
| --- | --- | --- |
| Страницы | Сохранённое значение из свойств; ≈, может быть устаревшим | Число страниц |
| Рисунки | Графические объекты основного текста, включая DrawingML/VML | Не определяется |
| Таблицы | Элементы таблиц основного текста, включая вложенные | Не определяется |
| Приложения | ≈ отдельные заголовки вида «Приложение А», «Приложение 1» | Не определяется |

**Подсчитать через Word (DOC / DOCX)** открывает каждый документ в отдельном скрытом Word только для чтения, перевёрстывает страницы и использует [ComputeStatistics](https://learn.microsoft.com/en-us/office/vba/api/word.document.computestatistics). Рисунки считаются как InlineShapes + Shapes (это графические объекты, не обязательно пронумерованные рисунки), таблицы — коллекция Tables. Приложения определяются приблизительно по отдельным заголовкам. Макросы и обновление ссылок отключаются; документ не сохраняется, настройка обновления ссылок восстанавливается. Пользовательские экземпляры Word не закрываются. Лимит ожидания — 120 секунд на файл; при подтверждённой изоляции зависший экземпляр счётчика завершается.

Статистика отображается в таблице и суммируется внизу с количеством файлов, для которых она получена. **«—» значит неизвестно**, а не ноль. Заголовки приложений с нестандартным оформлением могут не распознаться; ссылки на приложения не должны заменять ручную проверку. Колонтитулы/изображения не анализируются как содержание, OCR и семантического классификатора нет.

## Перенос и ошибки

В Windows используется обычное перемещение в пределах каталога (rename), а не жёсткие ссылки. Сохраняются файловые потоки и метаданные; поддерживаются длинные пути. Ошибка чтения для SHA-256 **не блокирует перенос**. Перед новым переносом список обновляется: файлы могли быть отсортированы в Explorer. Ошибки отдельных файлов не останавливают остальные; причина показывается локально. Если файл занят Preview/редактором, закройте его и повторите перенос.

После сбоя нажмите ту же кнопку для продолжения. В меню «Инструменты» есть сброс незавершённого плана; завершённые переносы он не отменяет. Старые журналы первой версии поддерживаются. Работайте с копией архива: общей отмены уже выполненных переносов нет.

## Приватность

Сессии и журнал сохраняются в `%LOCALAPPDATA%\CorpusPick` вне проекта и выбранного каталога. Они содержат чувствительные имена и пути; не публикуйте их. Извлечённый текст не сохраняется и не выводится в логи. Python-часть не выполняет сетевых запросов. Режим Word зависит от настроек подключённых служб Office и запускается отдельной командой пользователя. Реальный архив при разработке не используется.

Хеширование и подсчёт идут в фоне. Автообновления при каждом изменении в Explorer нет — используйте F5; это исключает постоянное перечитывание большого архива. Масштабная производительность ещё не измерена. Форматы кроме DOCX/PDF и DOC через Word пока не анализируются.

## Проверки

`python -m unittest discover -s tests -v`

Локальная проверка Word на искусственном документе: установите переменную `CORPUSPICK_TEST_WORD=1` перед запуском тестов. Без неё COM-тест пропускается. Все примеры в тестах искусственные, документы пользователя не открываются. Инструкции для разработки: `agents/README.md`.
