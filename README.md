# CorpusPick

Небольшое локальное приложение на Python для подготовки корпуса документов: вложенные папки, точные дубли и ручной отбор для RAG и будущих обучающих датасетов.

## Запуск на Windows

Нужен Python 3.10+ с Tcl/Tk (входит в обычную установку Python для Windows). Сторонние пакеты не нужны.
Дважды нажмите `Start-CorpusPick.cmd` или выполните `python -m corpuspick` из каталога проекта.

## Работа

1. Скопируйте документы в отдельный рабочий каталог и нажмите **Открыть каталог**. Сканирование читает файлы, но не меняет их.
2. Таблица показывает текущий и исходный пути, расширение, размер, группу точных дублей, оценку и категорию. Есть поиск по пути, фильтры и сортировка нажатием заголовка.
3. Выберите файл: текст TXT/DOCX отображается снизу; остальные документы можно открыть системной программой.
4. Выберите категорию и нажмите **0**, **1** или **2**. В таблице работают одноимённые клавиши, после оценки выбирается следующий файл. **Ctrl+Z** отменяет оценку. Категория сохраняется вместе с оценкой.
5. **Перенести в корень** перемещает все просканированные файлы из подпапок, независимо от оценки и фильтра. Совпадающие имена получают суффиксы `__1`, `__2`. Исходный путь остаётся в сессии и отчёте.
6. **Удалить пустые папки** удаляет только пустые подкаталоги. Непустые папки, ссылки и junction сохраняются.
7. **Экспорт CSV** сохраняет весь список с исходными путями, SHA-256, дублями, категориями и оценками. Выбирайте новое имя: существующие файлы не перезаписываются.

## Оценки

- **0** — исключить из будущего корпуса. Автоматически предлагается только для файла размером 0 байт.
- **1** — ручная проверка; начальная оценка остальных файлов, включая сканы и ошибки чтения.
- **2** — человек подтвердил полезность для своей задачи.

Полезность не определяется расширением или длиной. Дубли не удаляются и не получают 0 автоматически: человек выбирает экземпляр. Семантической классификации пока нет; выбранный документ ещё не является готовым обучающим примером.

## Сохранность и приватность

Приложение не содержит сетевых запросов, телеметрии, облачных моделей или OCR. Сканирование и хеширование выполняются в фоновом потоке. Системный просмотрщик — отдельная программа с собственными настройками сети и макросов.

Сессии, решения и журнал переносов сохраняются в `%LOCALAPPDATA%\CorpusPick` отдельно для каждого корня. Это конфиденциальные данные с именами и путями. Предпросмотр не сохраняется на диск. CSV также может содержать чувствительные сведения: храните его вне Git. Не выбирайте корень, содержащий каталог состояния.

Перенос создаёт жёсткую ссылку внутри одного файлового тома, проверяет SHA-256 и затем удаляет старое имя. Нужна поддержка hard links (например, NTFS); на неподдерживаемой системе операция остановится с сохранением оригинала. Не редактируйте файлы другими программами во время переноса. Автоматической отмены завершённых переносов нет — работайте с копией архива.

После сбоя откройте тот же корень и нажмите **Перенести в корень** для продолжения. **Сбросить план переноса** отменяет оставшиеся шаги, сохраняя завершённые, после чего можно пересканировать каталог. Если файл уже остался только в корне, сначала завершите восстановление кнопкой переноса. Удаление состояния лишает приложение исходных путей и возможности восстановления.

## Ограничения

- SHA-256 находит только побайтовые копии. DOCX/PDF одного документа и похожие версии требуют ручного сравнения.
- DOCX показывается без изображений, колонтитулов и точной вёрстки; текст ограничен 150 000 символами. Это не полный просмотр документа.
- PDF, сканы и старые Office-форматы открываются внешней программой. OCR пока нет.
- Сканирование хеширует все файлы; производительность большого архива не измерена, отмены текущей операции нет.
- Экспорт выбранных документов в отдельный датасет пока не реализован: доступны CSV и перенос рабочей копии в корень.

## Проверки

`python -m unittest discover -s tests -v`

Тесты создают искусственные файлы во временном каталоге: коллизии, дубли, разные периоды, изменение источника, сохранение оценок, восстановление после прерывания, блокировка сессии и предпросмотр. Для GUI-теста нужны рабочий Tcl/Tk и оконная сессия.

Инструкции для разработки: `agents/README.md`.
