# Передача работы — CSV структуры, быстрый анализ и остановка, 2026-09-12

## Последняя просьба
Пользователь сообщил о многочасовом переносе и потере соответствия исходным папкам. Потребовал CSV из нетронутого бэкапа с последующим сопоставлением плоского каталога, автосохранение CSV при переносе, Stop/продолжение, нумерацию, мультивыбор, постоянные колонки статистики, автоматический Unlock, удаление меню и подсчёта приложений.

## Реализовано
- «Бэкап: открыть без изменений» задаётся до открытия каталога. В этом режиме нет Unlock/изменений файлов/Word, состояние только во внешнем data root; CSV можно сохранить только вне исходного корня.
- Обычное открытие автоматически делает рекурсивный Unlock. Меню «Инструменты» удалено.
- №, Ctrl/Shift/Ctrl+A, сортировка всех колонок с индикатором направления. Стр./Рис./Табл. всегда видны, приложений нет.
- Итоги по всем документам без выбора или по выбранным. Знак > означает неполный охват, ≈ — сохранённые страницы. Только Word не гарантирует полноту DOC; неизвестные значения не приравниваются к нулю.
- Быстрый DOCX/XML и PDF; DOC страницы из SummaryInformation (olefile), без Word. Кнопка «Уточнить Word» для опционального полного пересчёта DOC/DOCX, не для бэкапа.
- manifest.py: переносимый CSV UTF-8 BOM с файлами, пустыми директориями, размером, SHA и исходными путями. Импорт сопоставляет по SHA+размеру, никогда не использует пути CSV для файловых действий.
- Одинаковый SHA в нескольких исходных папках: хранить/показывать все варианты origins, не выдумывать однозначное происхождение. По исходным путям работает поиск/выделение и действия по текущим путям.
- Автоматический <key>.structure.csv в LOCALAPPDATA/CorpusPick записывается до первого перемещения и после завершения/остановки. Ошибка первой записи блокирует перенос. Есть ручные «Сохранить CSV» и «Загрузить CSV».
- Stop/Esc через Event, отмена SHA по блокам; частичный анализ сохраняется, перенос продолжается с оставшихся файлов той же кнопкой после перезапуска.

## Производительность и происхождение
В прошлом полная JSON-сессия переписывалась для каждого файла, список просматривался линейно для каждого перемещения, хеширование повторялось при сканах. Теперь кэш по identity/size/mtime, dict для обновления пути, короткий append-only JSONL с fsync на шаг, полный checkpoint в начале/конце. Запись выполненного шага восстанавливается при старте; авария между rename и записью восстанавливается по идентификатору/хешу. Старые hard-link журналы поддержаны. Суффиксы коллизий используют счётчик вместо повторного поиска с 1.

## Проверено
39 тестов: 38 прошли с включённым тестом Word, интеграция корзины пропущена (ранее проверена, код не менялся). Добавлены CSV из бэкапа → импорт переименованного плоского корпуса → перезапуск; неоднозначные одинаковые хеши; read-only/ADS; кэш без повторных digest при переносе; ограниченное число полных save; остановка/продолжение/автоматический CSV; сбой CSV до перемещения; сбой перед append; экранирование CSV/запрет traversal; мультивыбор/сортировка/итоги. Всё на искусственных файлах.
Синтетический замер: 500 маленьких report.txt в разных подпапках — scan 3,61 с, перенос с кэшем и CSV 2,70 с. Не экстраполировать на реальные документы.

## Ограничения и честность
Первое хеширование читает весь архив; скорость зависит от носителя. Stop ждёт текущий системный вызов при файловых операциях, Word — текущий документ до 120 с. Метрики DOC без Word неполные, DOCX pages могут устареть/отсутствовать. PDF рисунки/таблицы не считаются. Истинную прежнюю папку одной из идентичных копий нельзя установить только по SHA. Физическое восстановление дерева не добавлялось: импорт даёт виртуальную структуру и управление текущими файлами. Пользовательские архивы, CSV, базы/логи состояния и реальные документы не читались.

## Уточнение: ручной подсчёт и отзывчивость
Удалена колонка «Примечание». Открытие/F5 делают Unlock (кроме бэкапа), обход метаданных и показ кэша, без новых SHA и статистики. SHA остаётся в операциях CSV/дублей/переноса. Кнопка «Статистика» считает выборку либо все документы. stats_worker.py использует отдельный переиспользуемый spawn-процесс: лимит 30 с на файл, Stop завершает принадлежащий приложению обработчик. Неудачные попытки повторяются следующей кнопкой. Прогресс передаётся числом, без deepcopy/перестроения всей таблицы каждую секунду; результаты обновляются по завершении/остановке. Режим Word не изменялся.
Проверено: 42 теста, 40 прошли, 2 опциональные интеграции Word/корзины пропущены. GUI проверен с рабочим Tk. Новые синтетические проверки: отсутствие анализа/SHA на открытии, выбранный DOCX в отдельном процессе, кэш и повтор ошибки, таймаут и перезапуск, отмена зависшего обработчика менее 5 с. Причина конкретного зависания на пользовательском документе не устанавливалась; архив не читался.

## Проводник и копирование названий
«Показать в Проводнике» использует SHParseDisplayName/SHOpenFolderAndSelectItems вместо CLI explorer /select (исключает проблемы экранирования). Передаётся только safe_path текущего документа, origin из CSV не используется. Отсутствующий файл показывает ошибку с просьбой обновить список. ПКМ → «Скопировать название» копирует текущие имена с расширением, несколько — через перенос строки.
Проверено на искусственных данных: GUI-тест экспорта CSV из вложенного бэкапа и импорта в плоский каталог проверяет текущий путь; копирование имён проверено без чтения/замены пользовательского буфера. Реальная интеграция Explorer с пробелами/кириллицей/запятой подтвердила выделение единственного нужного файла через Shell COM только в созданной тестовой папке. Включается CORPUSPICK_TEST_EXPLORER=1. Пользовательские документы не читались.

## Ctrl+A, префиксы и похожесть
Добавлен общий Ctrl-KeyPress для таблицы/окна с keycode 65 в Windows и Cyrillic_ef; текстовые поля сохраняют штатные сочетания. Кнопка «Убрать первый символ» проверяет выбранные identity, пустые/зарезервированные имена и занятые назначения, затем использует существующий журнал rename/CSV через flatten с подготовленным планом. Read-only запрещён; происхождение/кэш остаются. «По похожести»: metadata-only Dice триграмм нормализованных имён, порог .65, union-find, ограниченные 24 соседа в двух порядках; дополнительные ключи имя/размер/расширение. Не ML и не дубли, ограничения описаны в README.
Проверено 46 тестов: 43 прошли, 3 опциональные интеграции пропущены. Новые проверки: раскладки Ctrl+A, конфликт массового переименования/зарезервированные и пустые имена/сохранение происхождения и статистики после перезапуска/read-only; похожие названия с перестановкой слов, вторичные ключи, остановка. Только синтетические документы.

## Настраиваемая длина префикса
Кнопка переименована в «Убрать префикс». Вместо yes/no — simpledialog.askinteger «Сколько символов убрать?» с положительным числом, по умолчанию 1. ОК запускает trim_prefix для выбранных файлов, отмена ничего не меняет. Срез применяется к stem, расширение сохраняется, слишком короткие имена пропускаются. Проверено 47 тестов: 44 прошли, 3 опциональные интеграции пропущены; добавлен случай удаления трёх символов из нескольких имён и запрет некорректного количества.
