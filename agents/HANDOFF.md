# Передача работы — упрощение для Explorer, 2026-09-12

## Последняя просьба и процесс
Пользователь просматривает документы обычным Explorer/Preview и сам переносит подходящие файлы в другие каталоги. CorpusPick — помощник для каталогов и состава, а не просмотрщик или система разметки. Новая просьба имеет приоритет над прежним планом собственного предпросмотра и экспорта.

## Выполнено
- Убраны предпросмотр, запуск документов, CSV, категории отчёт/письмо, оценки и статус проверки.
- Кнопки: открыть каталог, перенести в корень, удалить пустые папки, удалить дубликаты.
- Растягивающаяся таблица с поиском/фильтрами/сортировкой. Тип, байты, группы SHA-256, происхождение файла сохранены.
- F5 обновляет после сортировки в Explorer; Enter/двойной щелчок показывает файл в Explorer; контекстное меню копирует путь.
- Фразу пользователя «2 — скорее да» интерпретировали как единственную необязательную метку, клавиша 2/контекстное меню. Запрос уточнения отправлен, ответа к моменту реализации нет. Оценки 0/1 и статуса проверки нет.
- Инструменты: рекурсивный Unlock (только Zone.Identifier), быстрый состав DOCX/страницы PDF, отдельный подсчёт DOC/DOCX через установленный Word.
- Статистика с неизвестными значениями «—», приближёнными «≈», итогами и покрытием по файлам.

## Исправление переноса
Прежняя реализация блокировала весь каталог при любой ошибке хеширования и зависела от hard links. Теперь Windows rename без перезаписи, длинные пути, свежий список перед новым планом; ошибки отдельных файлов не блокируют остальные. Байты сохраняются даже при ошибке хеша. Отдельные причины для занятого файла/отсутствия доступа/конфликта имени. Поддержано восстановление старых hard-link журналов. Реальную причину конкретного пользовательского файла не проверяли: архив не читался.

## Подсчёт
DOCX: XML основного текста, таблицы, графические объекты, отдельные заголовки приложений; страницы из сохранённых свойств приблизительные. PDF: только страницы через необязательный pypdf. DOC/DOCX через Word: отдельный процесс COM, read-only, Repaginate/ComputeStatistics, таблицы и графические объекты, заголовки приложений. Без сохранения документа, макросы/обновление ссылок отключаются. Word-просчёт имеет лимит 120 секунд на документ. Идентификация собственного Word через Window.Hwnd; пользовательские Word не завершаются. Настройка UpdateLinksAtOpen восстанавливается. Подключённые службы Office зависят от локальных настроек; не обещать сетевую изоляцию Word.

## Проверено
18 тестов прошли локально с CORPUSPICK_TEST_WORD=1: UI, ошибки чтения/занятости, коллизии, длинные пути, перенос без hard links с сохранением ADS, восстановление нового и старого журнала, Unlock с сохранением содержимого/других потоков, DOCX/PDF. Реальный COM Word проверен только на создаваемом искусственном DOCX: 2 страницы, 1 таблица, 1 приложение, исходный хеш не меняется. Отдельный COM-тест по умолчанию пропускается в CI без Word.

## Ограничения
Нет OCR, семантической оценки и анализа PDF-рисунков/таблиц. Подсчёт приложений эвристический, рисунки — объекты, не подписи. Нет постоянного автообновления/отмены долгого сканирования: F5. Большие архивы, реальные пользовательские документы и таймаут COM на намеренно зависшем Word не проверялись. Уже завершённые переносы не отменяются; работать с копией.

GitHub публичный. Предоставленный пользователем PowerShell-скрипт прочитан как пример кода, не запускался на архиве и не скопирован в репозиторий вместе с личными путями. Состояние приложения и реальные документы инструментами агента не читались.

## Дополнение: корзина и итоги
По новой явной просьбе пользователя добавлено удаление выбранного файла (Delete/контекстное меню) и кнопка удаления точных дублей. Только системная корзина Windows: IFileOperation с recycle-флагами и COM-отказом PreDeleteItem, если корзина недоступна; без fallback на безвозвратное удаление. Зависимости Send2Trash[nativeLib] (pywin32) добавлены в requirements и установлены локально.

Для дублей перед подтверждением свежий SHA-256-план; приоритет сохраняемого файла: «Скорее да», меньшая вложенность, имя. Перед каждой операцией повторно проверяются оба файла; изменения/исчезновение сохраняемого экземпляра отменяют удаление соответствующей копии. Незавершённый перенос блокирует удаление до завершения/сброса плана. Реальный архив не обрабатывался.

Итоги перенесены в отдельную небольшую сноску внизу: весь каталог, включая дубли, независимо от фильтра, с покрытием известных метрик. Добавлены тесты сохранения одного экземпляра, изменённого/исчезнувшего оригинала, отказа корзины, UI-удаления/итогов. Системная корзина проверена на единственном искусственном файле с последующим восстановлением; её прочее содержимое не перечислялось и не читалось. Интеграционный тест корзины включается CORPUSPICK_TEST_RECYCLE=1.
