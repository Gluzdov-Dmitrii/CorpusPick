# С чего начать
1. CONTEXT.md — задача пользователя и границы первого продукта.
2. PRIVACY.md — работа без передачи конфиденциального содержимого агентам.
3. IMPLEMENTATION.md — предлагаемые решения и этапы.
4. EVALUATION.md — отказ от TagSpaces и критерии следующей основы.
5. HANDOFF.md — фактически выполненное, исходные версии, ограничения и следующий шаг.

Эти инструкции предназначены всем будущим агентам проекта, а не только одному исполнителю.
Не принимайте предложения архитектуры за уже реализованные возможности.
Текущий процесс: просмотр в Explorer; CorpusPick управляет структурой/CSV, переносом и статистикой. Не возвращайте предпросмотр и классификатор без просьбы пользователя.
Пользователь буксует на ручном разборе архива уже несколько дней; первая полезная версия должна сокращать число действий.
Не создавайте дополнительных агентов автоматически: следуйте явной инструкции пользователя и правилам текущей сессии.
Обновляйте HANDOFF.md после значимого этапа: что изменено, что проверено, что осталось непроверенным.
