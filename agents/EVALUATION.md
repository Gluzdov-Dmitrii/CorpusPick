# Оценка основы CorpusPick
## TagSpaces: NO-GO по решению пользователя
Пользователь проверил интерфейс: предпросмотр приемлемый, но слишком много лишнего,
нет нужных функций отбора, часть возможностей платная. TagSpaces удалён.
Дальнейшая адаптация или повторная установка не планируется.

## Критерии следующей основы
- Компактная очередь документов: предпросмотр, исходный путь, рекомендация, решение одной клавишей.
- Ключевые функции без платных модулей.
- Локальная работа с документами и отдельное хранение метаданных вне исходного архива.
- Отсутствие обязательного OCR/индексирования перед началом просмотра.
- Рендеринг, OCR и сравнение не блокируют интерфейс.
- Если требуется переписывать большую часть готового продукта, рассмотреть минимальную оболочку
  из открытых компонентов. Это вариант, а не уже принятое решение.

## Тестовая подборка
Использовать только искусственные или явно публичные примеры.
evaluation/demo содержит простые TXT/HTML, не полный benchmark.
Добавить при реализации: русский DOCX с таблицами/колонтитулами, PDF с тем же текстом,
скан и смешанный PDF, длинный отчёт, копии с разными именами, разные отчётные периоды,
уникальное приложение, повреждённый файл и совпадающие имена в подпапках.

## Проверки
Измерять холодное/повторное открытие, время до читаемой страницы, переключение, память и зависания.
Сравнивать с Explorer на тех же искусственных файлах.
Проверять полноту просмотра и работу клавиатуры; показ первой картинки не равен готовности всего документа.
Проверять отмену решения, сохранение сессии, коллизии экспорта и целостность оригиналов.
Не обещать превосходство по скорости до измерений.
