# Конфиденциальность и целостность
## Граница между агентом и локальной программой
Агент может читать открытые исходники, инструкции и специально созданные тестовые материалы.
Конфиденциальные документы пользователь не хочет передавать в контекст или внешние сервисы.
Локальный алгоритм вправе читать их при запуске пользователем: байты, извлечение текста, OCR, сравнение.
Агенту можно возвращать только согласованную обезличенную статистику (количества, состояния, времена).
Имена файлов, полный путь, фрагменты текста и результаты NER тоже могут быть чувствительными.

## Во время разработки
- Не открывать реальные документы через shell, просмотрщик, браузер, изображения, скриншоты или UI-инспекцию.
- Не читать их кэши, индексы, OCR-sidecar, базы, crash dump, журналы и превью.
- Не копировать реальные документы в тестовые fixtures, Git, CI, отчёты или скриншоты.
- Не просить пользователя прислать документ для отладки; воспроизводить на искусственном примере.
- Не перечислять имена реальных файлов в вывод инструментов.
- Запрос на локальную обработку не отменяет запрет передачи содержимого агенту.
- Если пользователь впоследствии явно меняет эти ограничения, зафиксировать новый согласованный объём.
- Публичные зависимости можно скачивать. Обработка реального архива должна работать без внешних запросов.

## Требования к продукту
- OCR, сравнение и рекомендации локальны. Облачные LLM/OCR не подключать по умолчанию.
- Не заявлять, что upstream-программа полностью изолирована: проверить запросы обновления, внешние изображения,
  ссылки в документах, загрузку моделей и расширений. До этой проверки использовать только тестовые файлы.
- Не отправлять содержимое в телеметрию/отладочные endpoint. Не писать текст в stderr ошибок.
- Кэш, профиль, база решений и извлечённый текст считаются такими же конфиденциальными, как оригиналы.
- Вывести их в отдельный пользовательский data root вне Git. .gitignore — дополнительная защита, не хранилище секретов.
- В режиме отбора источник читается без изменений; метаданные и кэш хранятся во внешнем каталоге.
- Не удалять дубли и не перемещать оригиналы автоматически.
- Экспорт по явному действию пользователя: копирование без перезаписи, контроль целостности, журнал соответствий.
- Совпадающие имена из разных каталогов не перезаписываются. Включить восстановление после прерывания.
